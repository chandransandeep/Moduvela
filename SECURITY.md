# Security notice

Moduvela v0.1 is an **experimental local demonstration**, not a system for actual business records.

**Do not expose it to the internet, enter real customer/personal/financial information, or use it as a multi-user service.**

The prototype does not provide login, authorisation, encryption at rest, secure backups, audit history, tenant isolation, or tested concurrency. The CSRF form token and HTML escaping are limited safeguards, not substitutes for a security architecture.

To report a vulnerability, open a GitHub issue **without posting secrets, personal data, or executable exploit payloads**. If a private disclosure channel is enabled later, use that instead.

A security review is a prerequisite for any production offering.
