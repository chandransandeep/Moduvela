# Contributing to Moduvela

Thanks for helping improve independent, user-controlled business software.

## Development

1. Fork the repository and create a focused branch.
2. Use Python 3.10+.
3. Run `python -m unittest discover -s tests -v`.
4. Add tests for every behaviour change and document limitations.
5. Open a pull request with a clear explanation and a small demonstration.

## Scope for v0.1 contributions

Bug fixes, accessibility improvements, tests, clearer workflow templates and blueprint validation are welcome. Proposed external AI integrations must be optional, permission-based and must not silently send business descriptions to a third party.

Please use only wholly invented data. Never submit confidential employer, client, government or real customer materials.

## Design principles

- User consent before publishing or changing workflows.
- Privacy/local-first where feasible.
- Explicit supported capabilities over unsupported "AI magic" claims.
- Data portability, reversible changes and secure-by-default evolution.
